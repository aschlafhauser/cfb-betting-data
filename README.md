# CFB Betting Intelligence — Runtime Data

Public read-only runtime data for the 2026 College Football Betting Intelligence portal.

This repository contains only data already intended to be rendered in the public portal: current weekly board state, market snapshots, injuries/availability, live team stats, weekly expert matchup synthesis, completed results, frozen model snapshots, and official bet recommendations.

The application/code repository remains separate and private. Routine updates here are fetched by the portal at runtime and therefore do not require a Netlify production deploy.
